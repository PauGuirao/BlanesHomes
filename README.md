# BlanesHomes 🏠

A real estate analytics platform for Blanes, focusing on property valuation and market trends analysis.

## Features

- 🏘️ Interactive property map
- 📊 Zone-based market analysis
- 💰 AI-powered price estimation
- 📈 Market trend visualization
- 💎 Investment opportunities finder
- 🔍 Property comparison tool

## Tech Stack

### Frontend
- React
- Recharts for data visualization
- Mapbox for interactive maps
- CSS for styling

### Backend
- FastAPI
- Pandas for data processing
- XGBoost for price prediction
- Joblib for model serialization

## Getting Started

### Prerequisites
- Python 3.8+
- Node.js 16+
- npm or yarn

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
python main.py
